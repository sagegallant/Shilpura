# Shilpura 🪔

> A premium handicrafts e-commerce experience designed to showcase Indian artisan craftsmanship through a modern, elegant storefront.

**Shilpura** is a frontend e-commerce project focused on presenting traditional handicrafts through a polished digital shopping experience. The application combines a luxury-inspired visual design with product discovery, artisan storytelling, responsive layouts, dark mode, search, and a client-side shopping cart experience.

---

## ✨ Features

- 🛍️ **Product Showcase**
  - Browse handcrafted products with images, descriptions, and product details.
  - Designed around a premium e-commerce presentation.

- 🎨 **Artisan Profiles**
  - Highlight the people and craftsmanship behind individual products.
  - Provides additional context beyond the product listing itself.

- 🔎 **Client-Side Search**
  - Quickly find products through the storefront search experience.

- 🛒 **Shopping Cart**
  - Add products to a client-side cart.
  - Review selected products before proceeding through the checkout experience.

- 🌙 **Dark Mode**
  - Supports light and dark visual themes.

- 📱 **Responsive Design**
  - Designed to work across desktop, tablet, and mobile screen sizes.

- ✨ **Motion & Interactions**
  - Uses Framer Motion for interface animations and transitions.

- 🚀 **Static Deployment**
  - Configured for static export and deployment through GitHub Pages.
